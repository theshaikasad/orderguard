# OrderGuard hackathon film

## 0.0–14.0s / Every message can change an order.

A cake changes size. Then flavor. Then the date. For a small business, one missed message can become an expensive mistake.

## 14.0–25.0s / Meet OrderGuard.

Small businesses need more than another chatbot. Meet Order Guard: an AI sales and order operations agent, grounded in each seller’s business.

## 25.0–40.0s / Understands the request. Asks what is missing.

The customer asks for a chocolate cake. Meta Muse Spark understands the request and asks for the details it needs. A one kilogram cake for pickup is nine hundred rupees.

## 40.0–55.0s / Changes happen. The price stays correct.

Now make it eggless, with floral decoration. The backend applies the configured charges, and replaces the old quote. The new total is thirteen hundred rupees. Muse does not invent the price.

## 55.0–68.0s / A natural yes. An exact commitment.

A natural yes accepts this exact valid quote. The seller sees the saved commitment automatically. Acceptance does not verify payment, and it does not start production.

## 68.0–87.0s / Autonomous where possible. Human approval where necessary.

Here is the difficult case, verified in Scenario Lab. Production has already started when the customer changes the cake. Order Guard preserves the frozen production instructions and creates one clear owner review. A request is never silently turned into a promise.

## 87.0–102.0s / Teach it your business.

The same system works for a florist. The seller describes the catalogue and policies in natural language. Muse proposes sourced draft rules; the seller reviews and publishes the configuration.

## 102.0–116.0s / Bloom & Co. / ₹859

For Bloom and Company, the real verified order is eight hundred fifty nine rupees: roses, ribbon, a greeting card, and delivery. The accepted order keeps its original commercial terms.

## 116.0–127.0s / New price. New quote. Old commitment preserved.

After a published price change, a new quote is nine hundred fifty nine rupees. The earlier accepted order stays at eight hundred fifty nine. History is preserved.

## 127.0–150.7s / Language is probabilistic. Commitments should not be.

Muse interprets language and composes validated replies. Deterministic rules authorize prices, policies, and capacity. PostgreSQL persists sourced commitments atomically. One hundred fifty one backend tests pass, with eight complex scenarios verified using real Muse. The Instagram adapter is tested with synthetic events; live Instagram is not connected.

## 150.7–164.7s / OrderGuard.

Friendly conversations. Reliable orders. Human judgment when it matters. Order Guard. Less inbox. More business.
